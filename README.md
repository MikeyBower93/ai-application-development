### Useful Python "Stuff"

- Start a virtual environment within each section directory to install dependencies. For example `python3 -m venv venv`.
- Activate by running `source ./venv/bin/activate`.
- Deactivate by running `source ./venv/bin/deactivate`.
- Freeze requirements when install a dependency with ` pip freeze < requirements.txt`.
- Start Jupyter notebook with `jupyter notebook`.
- Connect Juypter Kernel to run with dependencies by starting the virtual environment and then running `python -m ipykernel install --user --name=myenv --display-name "Python (myenv)"`.
